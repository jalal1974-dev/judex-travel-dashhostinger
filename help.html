🏠 الصفحة الرئيسية

الصفحة الرئيسية هي نقطة الانطلاق. تضم الأقسام التالية:

  • القسم العلوي شعار الشركة مع روابط سريعة لجميع الصفحات، وزر تغيير اللغة/العملة، وزر واتساب للتواصل الفوري
  • القسم الترحيبي شعار الشركة ووصف مختصر مع زرين: "تصفح الباقات" و"تواصل معنا"
  • العروض المميزة آخر العروض الحصرية على الباقات والتذاكر — محدثة تلقائياً من قاعدة البيانات
  • معرض الوجهات 15 وجهة سياحية مع صور حقيقية — كل وجهة تظهر بثلاث بطاقات: باقات، فنادق، رحلات جوية — اضغط على أي منها للتصفح
  • الباقات المميزة باقات مختارة مع الأسعار، عدد الليالي، نوع الإقامة — محدثة تلقائياً
  • خدماتنا بطاقات تعريفية بكل خدمات الشركة: الباقات، الشارتر، العمرة، العروض، التأجير
  • تواصل معنا أزرار سريعة للاتصال أو واتساب

🎁 صفحة العروض

تعرض أحدث العروض والتخفيضات على الباقات والتذاكر والفنادق. كل عرض يظهر ببطاقة تحتوي على:

  • اسم العرض عنوان العرض ووصف مختصر
  • الوجهة اسم البلد أو المدينة
  • السعر يظهر بعملتك المختارة (دينار، دولار، ريال...)
  • نوع العرض هل هو باقة سياحية، تذكرة طيران، عرض خاص، أو عرض العيد
  • زر الحجز "احجز عبر واتساب" — يفتح نموذج حجز تملأ فيه بياناتك وتُرسل عبر واتساب
💡 العروض محدثة تلقائياً من قاعدة البيانات — تظهر فور إضافتها من لوحة التحكم

📦 صفحة الباقات

صفحة الباقات السياحية الشاملة — كل وجهة تعرض باقاتها الخاصة مع إمكانية التصفية والترتيب:

  • اختيار الوجهة ألسنة تبويب في أعلى الصفحة — اختر وجهتك للاطلاع على باقاتها
  • تصفية وترتيب اختر عدد الليالي، عدد النجوم، المنطقة، أو رتب حسب السعر (أقل/أعلى) أو النجوم أو الاسم
  • البطاقة اسم الفندق + عدد النجوم + الموقع + عدد الليالي + خطة الطعام + السعر للشخص + زر احجز
  • السعر يشمل الفندق + المواصلات (Transfer) + تذكرة الطيران
  • السعر لا يشمل رسوم التأشيرة (إلا إذا ذكرت صراحة)، النفقات الشخصية، التأمين الصحي
  • الطباعة والتصدير كل وجهة تحتوي على أزرار طباعة وتحميل PDF
💡 استخدم أزرار الطباعة أو PDF لتصدير معلومات الوجهة كاملة

🏨 صفحة فنادق ومواصلات

لمن يملك تذكرة طيران ويريد حجز فندق ومواصلات فقط — السعر لا يشمل تذكرة الطيران:

  • الوجهات المتاحة 5 وجهات: شرم الشيخ، أنطاليا، العقبة، إسطنبول، طرابزون
  • السعر يشمل الفندق + المواصلات (Transfer)
  • السعر لا يشمل تذكرة الطيران — هذه الصفحة لمن لديه تذكرة بالفعل
  • التصفية اختر عدد الليالي، النجوم، المنطقة مثل صفحة الباقات

✈️ صفحة الرحلات الجوية

تعرض رحلات الشارتر المباشرة من الأردن إلى أشهر الوجهات:

  • اختيار الوجهة ألسنة تبويب للمدن المتاحة (شرم، إسطنبول، طرابزون، باتومي، تبليسي، القاهرة، جدة، دبي)
  • شركات الطيران كل وجهة تعرض شركات الطيران المتاحة مع باقات مدة الرحلة والأسعار
  • خيارات الرحلة ذهاب وإياب أو ذهاب فقط
  • الحالة متاح، محدود، أو محجوزة بالكامل

🕌 صفحة العمرة
